# Security and public-safety reports

Do not open a public issue for a suspected credential, token, private endpoint, customer record, personal information or other confidential material.

Use GitHub's private vulnerability reporting for this repository when available. Otherwise contact the repository owner through their GitHub profile and share only the minimum information needed to locate and remove the material.

When reporting content, identify the path or URL and the category of data. Do not reproduce the sensitive value in the report.

The published mockup is a local-only UI reference. It has no backend, database or authentication. Its simulated data and URLs must not be treated as production configuration.
